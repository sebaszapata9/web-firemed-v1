# implementación

0. crear repositorio en GitHub
8. colocar: [git init]
9. colocar: [git clone https://github.com/sebaszapata9/web-firemed-v1.git]
1. utilizar carpeta como carpeta de proyecto
2. crear entorno virtual: [python -m venv venv_firemed]
3. activar entorno virtual: [venv_firemed\Scripts\activate.bat]
4. instalar django: [python -m pip install Django]
5. crear proyecto: [django-admin startproject firemed_web .]
6. crear app: [python manage.py startapp catalogo]
7. abrir terminal en VSC
10. activar app en settings
